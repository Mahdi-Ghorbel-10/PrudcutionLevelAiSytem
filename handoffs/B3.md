## Substep 3: deviations and choices

- In `dense` mode the score is the RRF score of the single dense list, not a cosine similarity. The spec does not say which score to use. This keeps every mode returning the same kind of number within a mode. The raw cosine is not returned by `VectorStore.query`.

## Substep 2: deviations and B2 notes

- B2 deviation affecting this code: Chroma stores page `0` for "no page". `query` and `chunks_by_id` map `0` back to `None` (`_stored`), so callers see `page=None` as before.
- `embed_query` embeds the query text as is. `BAAI/bge-small-en-v1.5` is usually used with a query instruction prefix. The spec does not mention one, so none is added. Worth checking in B7 as an ablation.

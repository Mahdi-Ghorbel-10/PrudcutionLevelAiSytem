## Substep 5: deviations and choices

- Both degradation paths catch `Exception`. A stage failing for any reason should not stop a query, and the spec asks for the query to keep working. The cost is that a bug in the stage is reported as a degraded stage, not raised. The stage name is in `degraded`, but the exception text is not recorded. Adding a log line is a small follow-up if B5 or B12 need it.
- When the reranker fails, the result is the RRF order cut to `rerank_top_k` (4), so its size matches a clean `hybrid_rerank` run. The spec said "the RRF order"; the order is the same either way, only the length differs.
- Dense mode with an embedder failure falls back to BM25 alone, as the spec says for the embedder in general. The `degraded` list shows the fallback.
